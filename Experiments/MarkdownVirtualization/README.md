# #127 预览虚拟化

普通Markdown的Web/双栏预览采用高度索引（Fenwick tree）和顶部/底部占位，仅挂载视口前后缓冲范围内的语法块。普通滚动与源码定位使用O(log n)高度/行号查找；单块文本更新同块数时只更新该块高度，首次载入、块数变化和宽度变化仍需O(n)索引工作。

高度初始为估计，显示后测量；图片加载及ResizeObserver更新高度，按源块锚点修正视野。离屏块只缓存Markdown，进入缓冲范围才解析HTML/公式。未变化的可见节点复用。虚拟模式使用独立flow-root块以获得稳定可测的高度（相邻段落外边距可能与旧版折叠外边距略有不同）；完整导出使用原block布局。

导出通过MarkdownExportRenderer显式关闭虚拟化，保留完整PDF/HTML内容；系统打印同样临时完整渲染。预览Cmd/Ctrl+A临时完整渲染，选择取消后恢复。完整导出/全选的工作量仍与文件大小有关。

## 测试

```sh
python3 Experiments/MarkdownVirtualization/run-tests.py
```

使用真实macOS WKWebView、仓库Marked/KaTeX/渲染脚本；创建临时测试窗口，不读取真实文档。测试一万块合成Markdown的首屏、远距离源码定位、末尾、离屏修改、动态图片高度、宽度变化、末尾缩放、缩短/清空、代码/公式、完整渲染、系统打印及全选恢复；还核对这些操作后的源块视野锚点。

同样输入另外运行GitHub回退标签codex/pre-127-preview-virtualization-20261117中的旧渲染器。原始数据见results.json及baseline-results.json。2026-11-17单次实测：旧版一万块全挂载，首屏约667ms；新版首屏挂载12块，约42ms，跳到第8000块附近挂载19块。时间包含requestAnimationFrame等待，随机器负载变化，不作为普遍性能承诺。

## 边界

- 文本数据仍完整保存在内存；Swift后台解析与补丁生成未改成跨编辑增量解析。
- 虚拟化单位是完整语法块，单个巨型列表、代码块或表格进入视口时仍可能较重，未任意切断语法。
- 未测真实触控拖选跨越很远距离、VoiceOver整篇阅读和所有外部HTML控件；源文的全文搜索、复制及导出仍应使用原生编辑器/完整导出。
- 字体、图片和估计高度首次变精确时滚动条长度可能改变；测试覆盖锚点保持，但未声称所有富文本组合均完全无跳动。
- 未安装正式App到用户设备，仍需真实大文件及移动端交互验收。

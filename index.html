核心功能

围绕老师每天真正会遇到的事情组织：教案要能长期维护，学生讲过什么要自动留下，课后资料要能稳定给出去。

自己的教案系统

内容按知识点组织，支持中心教案、章节教案和随堂笔记之间的联动，适合长期积累一套自己的教学体系。

学生授课记录

每个学生讲过哪些内容会被自动记录，随堂插入的知识点包也能沉淀到课反和后续同步流程中。

半自动生成课反

上课内容可自动写入课反结构，减少课后重复整理，让老师把精力放在判断和补充上。

课时统计与核算

自动记录课程时间、机构、学生和价格，按月统计课时与费用，也支持排课和周课程表。

随堂记录汇总

讲课时随手记录有用内容，之后可汇总回中心教案，让实际教学反过来推动教案变好。

通用文本格式

底层使用通用文本与 Markdown 思路，支持图片、公式和 HTML，迁移与长期保存更安心。

LaTeX 公式

公式可以点击进入源码编辑，编辑后自动渲染，适合物理、数学等高频公式场景。

物理画图

内置画图能力，面向受力分析、几何图形、坐标系等教学需求，后续会继续根据真实需求完善。

标准化单列表格

支持学生信息表、课反表等固定结构数据。多列表格暂时不是核心需求，所以当前优先做好单列表格。

一次上课的完整流程

软件的核心不是“写字”，而是把一节课前后真正发生的动作串起来。

准备教案 在中心教案或章节教案中维护知识点，按 Node 结构组织内容。
进入授课 选择学生和教案，开课后开始记录本节课内容、图片、公式和临时讲解。
随堂更新 插入知识点包、修改内容、生成脏包，必要时同步回中心教案。
下课导出 自动生成课反、统计课时，并导出 PDF / HTML 到学生同步目录。

技术结构

这套系统更像一个本地优先的教学资料数据库：内容可读、结构清楚、同步可控。

Markdown 语法，兼容 HTML 普通 Markdown 文本可以直接写，也支持下划线、高亮、加粗、图片和公式等教学常用内容。
Node 式内容结构 教案不是单纯一篇长文，而是按知识点、层级和包组织，便于插入、删除、剪切和同步。
中心化同步策略 中心教案作为母本，学生上课时使用的内容可以与中心教案保持联动，改动条目可继续更新到相关学生。
本地文件与通用格式 尽量使用可迁移、可备份、可同步的文件形式，减少被单一平台或私有格式锁住的风险。

导出与同步

下课后的资料整理应该尽量自动完成，学生拿到的内容也应该始终是最新版本。

PDF 与 HTML

下课时自动生成 PDF 和 HTML。HTML 模板保留更灵活的排版能力，PDF 则适合直接发给学生。

网盘同步

导出结果可以放入学生同步文件夹，再由百度网盘或其它同步工具完成分发。

排课导出

排课系统和周课程表可以导出给合作伙伴，也可以按机构或学生生成统计视图。

目标很简单：老师上完课之后，不需要再从一堆零散笔记里手动整理资料。软件应该把能确定的事情自动做完，把需要老师判断的地方留给老师。

继续完善中

画图、公式、课表、统计和多端体验都还会继续迭代。尤其是物理画图和之后可能加入的数学画图，需要更多真实使用场景来推动完善。

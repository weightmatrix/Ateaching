快速开始

第一次使用时，建议按这个顺序建立基础数据。这样授课、课反、课时统计和同步文件夹才能串起来。

1

建立学生

在学生页添加学生，并维护学生基础资料。需要同步资料时，为学生设置同步文件夹。

2

准备教案

在教案系统中建立中心教案和章节教案。NodeMarkdown 适合按知识点组织长期维护的内容。

3

配置统计

如果需要课时统计，先添加机构，再给学生设置机构和课时价格。课时价格按 2 小时价格填写。

4

进入授课

选择学生、选择教案，点击开课后开始记录内容。下课时系统会处理课反、课时和导出。

5

导出给学生

下课导出的 PDF 和 HTML 会进入学生同步文件夹中的指定目录，方便通过网盘同步给学生。

6

检查备份

重要数据建议定期备份，尤其是系统文件夹、学生文件夹、中心教案和统计课单。

核心模块说明

软件模块较多，但主线清楚：教案负责内容，授课负责过程，统计负责课时，档案和同步负责长期管理。

教案系统

  • 支持中心教案和章节教案。
  • 内容按 Node 层级组织，适合拆成知识点包。
  • 支持图片、LaTeX 公式、Markdown 和部分 HTML 样式。

授课系统

  • 记录学生本节课讲过的内容。
  • 随堂可插入 H3 知识点包。
  • 下课时生成课反、导出 PDF / HTML，并处理同步。

NodeMarkdown 编辑器

  • 层级化 Markdown，支持源码编辑和即时渲染。
  • 公式点击可编辑，确认后自动渲染。
  • 图片可设置宽度，并参与 PDF / HTML 导出。

课时统计

  • 按学生、机构、月份统计课时和费用。
  • 支持排课、周表、修改课程和导出课程表。
  • 机构删除不会破坏历史上课单快照。

画图功能

  • 面向物理教学中的受力图、斜面、坐标系和几何结构。
  • 支持画笔、文字、图形、橡皮、撤销恢复等基础操作。
  • 后续会继续按实际教学需求完善。

单列表格

  • 适合学生信息、课反模板等标准化文本数据。
  • 支持导出图片，方便保存和分享。
  • 当前重点是稳定做好单列表格，多列表格暂不作为核心功能。

常见问题

下课后学生资料没有更新怎么办？

先检查该学生是否设置了同步文件夹，再确认下课导出的 PDF / HTML 是否生成到学生同步文件夹的对应子目录。如果使用网盘同步，还需要确认网盘客户端正在运行并已完成同步。

课时统计没有自动添加课程怎么办？

请检查统计功能是否打开，学生统计设置里机构和课时价格是否完整。机构为空时不会静默添加课时记录。课时价格是 2 小时价格，不是 1 小时价格。

公式显示不正常怎么办？

请优先确认公式是否是标准 LaTeX 语法。若某个特殊符号显示异常，请把原始公式、截图和出现位置一起发给开发者，方便补充支持。

图片路径不对怎么办？

请说明是在授课模式、教案编辑模式还是普通 Markdown 中插入图片。不同模式的图片目录规则不同，反馈时最好附上生成的 Markdown 图片链接。

可以迁移数据吗？

软件尽量使用通用文本、JSON、CSV、图片、PDF、HTML 等文件形式。迁移前建议完整备份系统文件夹、学生文件夹和教案文件夹。

数据与备份

授课数据很重要。任何系统都应该默认重视备份，尤其是长期积累的教案和学生资料。

建议

定期备份

建议定期备份 App 的系统目录、教案目录、学生目录和同步目录。重要修改前可以额外手动复制一份。

注意

不要手动破坏结构

可以查看和备份文件，但不建议随意改名、移动或删除系统生成的 JSON、CSV、图片目录和教案目录。

重要

删除前确认

删除学生、机构、教案、课程记录前请确认已经备份。历史上课单会尽量保留快照，但用户主动删除的文件无法保证恢复。

如果你不确定某个文件能不能删，建议先不要删，先邮件问一下。真实授课数据比“清理一下看起来舒服”更重要。

反馈格式

为了更快定位问题，反馈 Bug 时建议包含以下信息。尤其是编辑器、公式、图片、同步、统计这类问题，复现步骤非常关键。

标题：简短描述问题 设备：Mac / iPad / iPhone 系统版本： App 版本： 问题发生位置： 例如：授课 - 某学生 - NodeMarkdown 编辑器 - TextKit2 管线 复现步骤： 1. 2. 3. 预期结果： 实际结果： 附件： 截图、录屏、出错文字、相关公式或生成的 Markdown 链接
